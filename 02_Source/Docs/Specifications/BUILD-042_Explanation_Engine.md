# 1. Objective

Explanation Engine is responsible for converting a LearningContent model
into structured educational explanations.

The engine does not create learning content.

It explains learning content.

---

# 3. Responsibilities

Explanation Engine SHALL:

- Explain concepts.
- Explain formulas.
- Explain variables.
- Explain mathematical meaning.
- Explain scientific meaning.
- Explain each learning step.
- Generate learning summaries.
- Generate learning tips.
- Generate common mistakes.
- Generate learning notes.

---

# 4. Non Responsibilities

Explanation Engine SHALL NOT:

- Access Database.
- Access Repository.
- Access Services.
- Modify LearningContent.
- Generate Questions.
- Generate Visualization.
- Perform Learning Path Planning.
- Execute AI inference directly.

---

# 5. Input

LearningContent

Generated by:

ContentMapper

---

# 6. Output

Explanation

Explanation represents the complete explanation package
for one LearningContent.
